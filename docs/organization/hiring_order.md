# Hiring and activation order
Deterministic order is ascending (priority, role ID) from `ai_workforce.yaml`; dependencies must precede candidates. This refines the coarse priority bands in `workforce-roles.json` to put independent QA/security before implementation.
Phases: governance (ai-hr-001, chief-architect); assurance (qa, security); delivery (primary-coder, devops, data); domain preparation (research, education, tax-legal); operations (content, ops). Each phase exits only after all its candidates meet the documented independent probation rubric.
ORG-HR-02 delivers definitions only. ORG-HR-03 verifies the core team after this plan; ORG-HR-04 verifies coverage, runtime enforcement and receipts before technical execution resumes. Domain hiring is conditional, not an automatic scheduled launch.
Activate serially, maximum one task, only after all dependencies graduate, three probation passes, current receipts and separately verified runtime gates. No calendar date substitutes for evidence. Human Owner reviews HR and security until independent qualified reviewers exist; candidates never approve themselves.
Budget: zero incremental spend authorized by this plan; existing infrastructure remains within the documented 0–30 USD/month ceiling. HR owns cost accounting, records cost-center attribution and blocks any invocation without confirmed available budget. No subscription, paid fallback, capacity increase or self-raised tier is authorized.
Readiness work for 06K-C remains read-only; production apply is R4 with explicit human approval. 07A waits for migration, 07B deployment and 07C end-to-end execution retain human gates. Node migration remains blocked pending DR V1.2; this plan changes no roadmap status or production state. Supervision differs from hiring prerequisites: Human Owner supervises HR, architecture and security; HR coordinates staffing; chief-architect supervises coder, DevOps and data; QA reviews delivery independently; research supervises education, tax-legal and content preparation; ops reports to HR. Human specialists retain consequential domain sign-off.
