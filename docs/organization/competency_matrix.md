T0–T4 map to MODEL_TIER_0–4: deterministic checks, local SLM, economical cloud, premium reasoning, human expert. Card tier is a proposed maximum, not an entitlement; budget and verified capability gate every invocation. T4 review is external human oversight.
Antigravity leads planning/implementation; Codex supports implementation/review; Gemini designs tests; Claude reviews domain reasoning. Failover uses only the card stage's provider-mesh candidates after equivalent probation and a reviewed card revision; no automatic tier or permission increase. ChatGPT is a configured alternative, not a verified hire.
Cloud clients use the Supabase queue; Dell offline leaves work queued. Preserve tenant boundaries, HAIP idempotency and Apps → Packages → Contracts layering. Data proposes offline models only; DevOps proposes runbooks only.
Tools use canonical abstract permission IDs, as future allowlists only. Current permissions are empty; proposed reads/writes are limited to organization documentation. No shell, network, DB, publishing, secret access or live telemetry is granted. Coding/test tools await separate task-scoped sandbox authorization.
Any failed check, stale evidence, unknown capability or unavailable eligible provider stops allocation. Preserve revocations, return to DENY_ALL on invalid policy, and require independent re-verification; after three provider failures observe the mesh's 120-second cooldown without widening scope. Provider comparison is a qualification hypothesis: Antigravity for implementation throughput, Codex for independent code review, Gemini for test design, Claude for domain review, ChatGPT for alternate planning. Compare identical fixtures using pass rate, p95 latency and measured cost per accepted task; no vendor ranking or current price is asserted. T0 avoids model spend; T1 trades cloud spend for Dell capacity/availability; T2 favors routine work; T3 requires demonstrated quality gain within budget; T4 adds human review delay. Layer ownership: chief-architect owns cross-layer contracts; primary-coder covers websites, Control Center, serverless APIs and dispatcher; data covers tenant schemas/queues; devops covers Dell, gateway and recovery; QA/security review every layer. Education owns org-02, tax-legal org-03, content org-04/05/06 with research support; shared governance/engineering/ops serve all six under explicit tenant scope. The [machine matrix](../../config/organization/competency_matrix.json) leaves context_tokens null until a pinned model and measured input/output limits are verified. Admission requires the complete task, policy and evidence to fit that limit; never truncate safety context. Empty fallback lists disable failover until equivalent qualification and a reviewed revision. max_cost_usd=0 is the incremental task-spend ceiling.
